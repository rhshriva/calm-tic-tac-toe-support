# Tic Tac Toe for iPhone and iPad

A native, accessible Tic-Tac-Toe game built with Swift and SwiftUI.

## Included

- Human vs Computer and local two-player modes
- Easy, Medium, and Unbeatable computer difficulty
- Scorekeeping and instant rematches
- Light and dark mode support
- Responsive single- and two-column layouts for iPhone and iPad
- VoiceOver labels and non-color game-state cues
- Unit tests for game rules and AI decisions

## Requirements

- Xcode 26 or later
- iOS 17 or later

## Run

1. Open `TicTacToe.xcodeproj` in Xcode.
2. Select an iPhone or iPad simulator, or a connected device.
3. Press Command-R.
